# Política de Segurança

## Como relatar uma vulnerabilidade

Use o **relato privado de vulnerabilidades do GitHub** deste repositório (aba *Security* → *Report a vulnerability*). Não abra issues públicas com detalhes exploráveis e não inclua dados pessoais reais nos relatos.

## Escopo

Importador do ZIP, armazenamento local, aplicativo desktop e, quando existirem, backend de contas/licenças/pagamentos.

## Versões suportadas

O projeto ainda não tem versão de produção; correções de segurança são aplicadas na branch `desenvolvimento`.

## Documentação

Modelo de ameaças, requisitos e registro de riscos em `docs/security/`. Os riscos residuais e limites de proteção estão declarados ali e em `docs/DATABASE_SECURITY.md`.
